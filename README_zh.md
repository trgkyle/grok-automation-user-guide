# 🚀 Grok 自动化 v2.4.8 - Grok.com AI 自动化 [![English](https://img.shields.io/badge/English-blue)](README.md) [![Tiếng Việt](https://img.shields.io/badge/Tiếng%20Việt-green)](README_vi.md)

**Grok 自动化** 是一款强大的生产力工具，旨在增强您在 xAI 的 grok.com 上的创作流程。告别手动逐个输入提示词——实现流程自动化，大规模生成高质量内容。

-----

## ✨ 主要功能

* **🚀 先进的批处理：** 排队数十个或数百个提示词，让扩展程序自动处理提交和生成。
* **🧩 工作流（可视化拖放编辑器）：** 在画布上连接提示词、图片和生成节点——例如先生成图片，再自动用这些图片生成视频。可保存多个工作流，运行单个节点或全部运行，并以文件导入/导出。
* **📊 智能电子表格导入：** 从 `.txt` 或电子表格文件（`.xlsx`、`.csv`）导入提示词，支持工作表和列的选择以及实时预览。
* **🎬 文本转视频自动化：** 从文本描述生成令人惊叹的视频。支持带自定义延迟的批处理。
* **🖼️ 帧转视频：** 使用静态图片并添加自动运动效果，创建动态视频。
* **🧩 素材转视频：** 将多个界面组件或角色图片合成为一段视频动画。
* **🖼️ 文本转图片批量处理：** 同时创建多张图片，支持多种宽高比（16:9、9:16、1:1、2:3、3:2）。
* **🔄 图片转图片：** 使用 AI 结合文本提示词对现有图片进行变换和增强。
* **⚙️ 专业控制套件：**
    * **并发 Prompt：** 同时处理多个提示词以节省时间。
    * **智能延迟：** 设置提示词之间的自定义间隔，以有效管理速率限制。
    * **自动高清 (Upscale) 并下载：** 自动触发高清增强并保存最终结果到您的电脑。
    * **自动更改文件名：** 自动重命名已下载文件以保持整洁。
    * **保存到文件夹：** 为每个项目的下载文件指定自定义子文件夹。
* **🎭 自动添加角色图片：** 根据文件名中的角色名称自动匹配并附加图片到提示词。
* **📊 实时队列管理：** 通过侧边面板（Side Panel）中的可视化状态栏和活跃提示词列表监控您的生成进度。
* **📂 有序的文件管理：** 自动将下载内容按项目分类到文件夹中，保持您的工作空间整洁。
* **🔧 快速修复：** 一键工具，用于恢复视频或图片生成错误。
* **💳 套餐管理：** 登录以查看您的套餐并追踪每日提示词使用情况。
* **🌐 多语言支持：** 支持 20 种语言（英语、越南语、中文、韩语、西班牙语、日语、法语、德语、葡萄牙语、阿拉伯语、印地语、印度尼西亚语、意大利语、荷兰语、俄语、泰语、菲律宾语、土耳其语、乌尔都语和孟加拉语）。

## 📖 使用指南

### 开始使用

1. **访问 Grok.com**
   - 打开 [grok.com/imagine](https://grok.com/imagine)
   - 该扩展程序仅在 Grok 的 "Imagine" 页面上运行。

2. **打开扩展程序**
   - 点击 Chrome 工具栏中的扩展程序图标。建议将其固定以方便访问！

3. **配置批量设置**
   - 在 **控制** 标签页中，您可以设置：
     - **并发 Prompt：** 同时运行的提示词数量。
     - **提示间隔：** 每次提交提示词之间的等待时间。
     - **保存到文件夹：** 下载文件的子文件夹名称。
     - **自动更改文件名：** 开启/关闭自动文件重命名。

4. **选择模式**
   - 从可用的生成模式中选择：**文本转视频**、**帧转视频**、**素材转视频**、**文本转图片** 或 **图片转图片**。

---

### 1. 文本转视频模式

1. 选择 **文本转视频** 模式。
2. 在输入框中输入提示词（每个提示词之间用 **空行** 分隔）。
3. 或者，点击 **上传** 图标导入提示词：
   - **文本文件 (`.txt`)**：直接加载提示词列表。
   - **电子表格 (`.xlsx`, `.csv`)**：打开一个导入对话框。选择工作表标签页和提示词列（扩展程序会自动推荐包含最多数据的列）。您可以在导入前预览前 6 行并查看总行数。
4. 点击 **运行** 开始批量处理。

**示例提示词：**
```
一个充满霓虹灯的未来派赛博朋克城市，雨水倒映着灯光。
摄像机穿过狭窄的小巷。

一个宁静的日本花园，樱花飘落进池塘。
摄像机缓慢放大观察下方游动的锦鲤。
```

---

### 2. 帧转视频模式

1. 选择 **帧转视频** 模式。
2. 点击上传或拖放源图片。
3. 输入提示词（用空行分隔）。每张图片将与每个提示词一起处理。
4. 在 **设置** 中，选择 **图片处理选项**：
   - *仅使用起始帧* — 每个提示词使用一张图片。
   - *使用起始帧和结束帧* — 每个提示词使用两张图片。
5. 点击 **运行**。

---

### 3. 素材转视频模式

1. 选择 **素材转视频** 模式。
2. 上传您想要制作动画的组件图片或角色图片。
3. 输入提示词（用空行分隔）。
4. 可选择开启 **自动添加角色图片**，以自动附加文件名与提示词中角色名称匹配的图片。
5. 在 **设置** 中，设置 **每个提示词最大输入图片数**（1–10）以控制每个提示词使用的图片数量。
6. 点击 **运行**。

---

### 4. 文本转图片模式

1. 选择 **文本转图片** 模式。
2. 为您的图片输入详细描述。
3. 在设置标签页中配置所需的 **宽高比** 和 **图片模型**。
4. 点击 **运行**。

---

### 5. 图片转图片模式

1. 选择 **图片转图片** 模式。
2. 上传您想要变换的源图片。
3. 输入提示词（用空行分隔）。
4. 可选择开启 **自动添加角色图片**，根据文件名自动附加图片。
5. 在 **设置** 中，设置 **每个提示词最大输入图片数**（1–10）。
6. 点击 **运行**。

### 🧩 工作流（可视化拖放编辑器）

工作流是用于多步骤流程的可视化拖放编辑器——例如：先生成几张图片，再用这些图片生成视频，然后用另一个提示词延续每个视频。它在独立窗口中打开，并在您已打开的 grok.com 标签页上运行。

#### 打开工作流

* 在控制标签页中点击 **工作流**（最下面一排按钮）。
* 已在侧边面板输入提示词或上传图片？将鼠标悬停在 **工作流** 上并点击 **转换为工作流**：提示词、每个提示词的模式和图片都会变成工作流中的节点，可直接运行。

#### 界面

| 区域 | 内容 |
| :--- | :--- |
| **左侧** | **节点**（点击或拖到画布上）和 **我的工作流**（已保存的工作流列表） |
| **顶部栏** | 画布工具：撤销/重做、**自动排列**、适应视图、**示例**、清空。右侧：**详情** 按钮、**快捷键** 和 grok.com 标签页状态 |
| **画布** | 您的节点。左上角：**全部运行**（运行时还有 **停止**）和 **开启后台模式** |

**详情** 按钮提示需要注意的情况：有问题阻止运行时显示红色/黄色的 **问题 (n)**，生成时显示 **运行中 3/8**。点击可打开面板，查看问题（点击问题跳到对应节点）、进度、运行计划及所用设置。

#### 节点

| 节点 | 作用 |
| :--- | :--- |
| **输入提示词** | 一个或多个提示词，用 **空行** 分隔 |
| **上传图片** | 您的图片（可直接把文件拖到节点上）。悬停图片：🔍 放大查看，✕ 删除，拖动角上的手柄可调整顺序。顺序（或排序菜单）决定每个提示词使用哪张图片 |
| **生成图片** | 文本生成图片；连接图片后为图片生成图片。选项：**每个提示词的图片模式**、**每个提示词的最大输入图片数**、**自动添加角色图片** |
| **生成视频** | 文本生成视频；连接图片后为 **帧图生成视频** / **素材生成视频**。选项：**每个提示词的视频模式**、每个提示词的图片数（与侧边面板设置共用）、**自动添加角色图片**（素材生成视频） |

生成节点会根据第一个提示词自动命名（`image_…` / `video_…`）。每行提示词都会显示它将使用的图片，方便运行前检查。预览区域采用设置中的 **宽高比**（9:16 的节点更窄更高）。

**帧图生成视频** 可以只用起始帧，也可以用 **起始帧和结束帧**（与侧边面板设置共用）。使用起始帧和结束帧时，每个提示词按顺序使用 2 张图片（延续上一个视频的提示词使用 1 张）；图片不够时，节点会显示警告且无法运行。

#### 连接节点

从节点右侧的圆形连接点拖出，**放到另一个节点的任意位置**——会自动选择合适的输入口。拖动时，可以连接的节点会高亮。

| 从 | 到 | 含义 |
| :--- | :--- | :--- |
| 输入提示词 | 生成图片 / 生成视频 | 要生成的提示词 |
| 上传图片 | 生成图片 / 生成视频 | 参考图、起始帧或素材 |
| 生成图片 | 生成图片 / 生成视频 | **生成的图片** 作为该节点的输入（图片就绪后才运行） |
| 生成视频 — **最后一帧** 输出 | 生成视频 | 后一个视频 **从前一个视频的最后一帧继续** |
| 生成视频 — **最后一帧** 输出 | 生成图片 | 每个视频的 **最后一帧** 作为输入图片（视频就绪后才运行） |

#### 运行

* **全部运行**（左上角，或 `Ctrl/⌘ + Enter`）按正确顺序运行整个工作流：需要生成图片的节点会在图片就绪后自动开始。
* 如果 **全部运行** 不可用，顶部栏会显示 **问题 (n)**：点击查看需要修复的内容。
* 每个生成节点都有自己的 **运行** 按钮，只运行该节点。在其依赖的节点完成之前按钮不可用（悬停可查看原因）。
* **停止** 取消仍在运行的任务。
* 运行时，连向正在生成的节点的连线会发光并流动，让您看到工作流进行到哪一步。

> ⚠️ **grok.com 标签页不可见时 Chrome 会暂停它**（例如工作流窗口全屏遮住它时）。点击 **开启后台模式**（工作流中 **全部运行** 按钮下方，或侧边面板中），然后在 Chrome 的对话框中选择 grok.com 标签页。这会共享 grok.com 标签页（不会录制或发送到任何地方），让它在其他窗口后面继续生成。绿色的 **后台运行中** 标识表示已开启；点击 ✕ 关闭。

#### 结果

结果直接显示在生成节点中。悬停结果：🔍 放大查看，✕ 删除（橡皮擦按钮清除该节点的全部结果）。悬停时视频自动播放。文件仍会照常下载。

下一个节点使用 **每个提示词的第一个结果**。要换成别的结果，拖动结果左上角的手柄放到另一个结果上即可交换位置（图片和视频均可）。

#### 管理工作流

在左侧的 **我的工作流** 中：**新建**、**导入**，以及每个工作流的 **⋯** 菜单——**重命名**（或双击名称）、**复制**、**导出**、**删除**。所有更改都会自动保存。

* **导出** 会下载一个 `.json` 文件。文件开头有 `//` 注释行，描述所有节点、属性和连接方式，因此您可以把文件交给 AI 助手，让它编写新的工作流。导入时会自动去掉这些注释行。
* 用 **导入** 按钮导入文件，或直接 **把 `.json` 文件拖到画布上**。

## 💡 提示与最佳实践

1. **等待时间：** 如果遇到速率限制，请增加设置中的 **随机延迟**。
2. **并发运行：** 建议从 1 个并发提示词开始，根据账号支持情况缓慢增加。
3. **提示词编写：** 尽可能具体！详细的提示词会带来更好的 AI 生成效果。请用清晰的空行分隔多个提示词。
4. **文件组织：** 使用 **保存到文件夹** 字段，将项目下载内容整理到命名子文件夹中。
5. **角色图片：** 将图片文件命名为角色名称（如 `hero.png`、`villain.jpg`），并开启 **自动添加角色图片** 以自动匹配。
6. **视频时长：** 使用 *6 秒（拼接）* 或 *10 秒（拼接）* 选项将提示词串联成一段长视频。最后一个提示词始终使用非拼接时长。
7. **快速修复：** 如果生成卡住或出错，请点击控制标签页中的 **修复错误** 按钮。

## 🔧 故障排除

| 问题 | 解决方案 |
| :--- | :--- |
| **扩展程序未激活** | 确保您位于 [grok.com/imagine](https://grok.com/imagine)。如果需要，请刷新页面。 |
| **生成错误** | Grok 可能正忙。扩展程序将根据您的 **最大重试次数** 设置自动重试。使用 **修复错误** 手动恢复。 |
| **下载无效** | 确保 Chrome 设置中已 **关闭** "在下载前询问每个文件的保存位置"。 |
| **需要登录** | 请确保您已登录您的 Grok.com 账户。 |
| **图片不足** | 在帧转视频模式中，请确保已上传足够数量的图片以匹配提示词数量。 |
| **工作流：结果一直停在“生成中”** | Chrome 暂停了被遮住的 grok.com 标签页。开启 **开启后台模式**（或 **后台运行**），或保持 grok.com 标签页可见。 |
| **工作流：某个节点的运行按钮不可用** | 将鼠标悬停在按钮上：先运行它依赖的节点，或修复提示的问题（例如未连接提示词）。 |
| **工作流：全部运行不可用** | 点击顶部栏的 **问题 (n)** 查看需要修复的内容；点击某个问题可跳到对应节点。 |
| **工作流：“未找到 grok.com 标签页”** | 在标签页中打开 [grok.com](https://grok.com)（顶部栏的绿点表示已连接）。 |
